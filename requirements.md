# Requirements Document - Farm Management CRM

## Functional Requirements
1. User should be able to create Farm with location and area
2. User should add multiple Crops under one Farm
3. System should track Harvest quantity and quality
4. System should calculate total revenue automatically (Quantity * Price)
5. Admin should see dashboard with total yield and revenue

## Non-Functional Requirements
1. Easy to use interface
2. Mobile responsive
3. Secure data access

## User Stories
- As a Farm Owner, I want to see my total farms and crops in one place
- As a Farmer, I want notification 7 days before harvest
- As a Admin, I want yield reports farm-wise

## Tech Stack
- Salesforce CRM (Custom Objects, Flows, Validation Rules, Reports, Dashboard)
- GitHub for Documentation and Version Control
- SkillWallet for Project Verification
